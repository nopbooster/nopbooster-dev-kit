# 4.70 → 4.80 (verified against 4.70.5 and 4.80.9 source)

## Build

| Item | 4.70 | 4.80 |
|---|---|---|
| `<TargetFramework>` | net8.0 | **net9.0** |
| SDK / VS | .NET 8 SDK, VS 17.9+ | .NET 9 SDK, VS 17.12+ |
| `plugin.json` `SupportedVersions` | `["4.70"]` | **`["4.80"]`** |
| `.csproj` paths | relative `..\..\` | **`$(SolutionDir)`-based** |

Bump the plugin's own `Version` too, so `UpdateAsync` and `Update` migrations run.

`.csproj` diff applied to every core plugin in 4.80:

```diff
-    <TargetFramework>net8.0</TargetFramework>
+    <TargetFramework>net9.0</TargetFramework>
-    <OutputPath>..\..\Presentation\Nop.Web\Plugins\{Group}.{Name}</OutputPath>
+    <OutputPath>$(SolutionDir)\Presentation\Nop.Web\Plugins\{Group}.{Name}</OutputPath>
 …
-    <ProjectReference Include="..\..\Presentation\Nop.Web\Nop.Web.csproj" />
-    <ClearPluginAssemblies Include="$(MSBuildProjectDirectory)\..\..\Build\ClearPluginAssemblies.proj" />
+    <ProjectReference Include="$(SolutionDir)\Presentation\Nop.Web\Nop.Web.csproj" />
+    <ClearPluginAssemblies Include="$(SolutionDir)\Build\ClearPluginAssemblies.proj" />
 …
-    <MSBuild Projects="@(ClearPluginAssemblies)" Properties="PluginPath=$(MSBuildProjectDirectory)\$(OutDir)" Targets="NopClear" />
+    <MSBuild Projects="@(ClearPluginAssemblies)" Properties="PluginPath=$(OutDir)" Targets="NopClear" />
```

Build from the solution afterwards (or pass `-p:SolutionDir=…/src/`), otherwise `$(SolutionDir)` is empty.

## Permissions — the largest change

- **Removed:** `StandardPermissionProvider`, `IPermissionProvider`, `IPermissionService.InstallPermissionsAsync(provider)` / `UninstallPermissionsAsync(provider)`.
- **Added:** `StandardPermission.{Area}.{CONSTANT}` strings, `[CheckPermission(...)]` filter (`Nop.Web.Framework.Mvc.Filters`), `IPermissionConfigManager` + `PermissionConfig`, `IPermissionService.InsertPermissionsAsync()`, `DeletePermissionAsync(string)`, `InsertPermissionMappingAsync(roleId, params string[])`.
- Admin ACL became granular (view vs create/edit/delete).

Rewrite pattern (from core's Google Analytics plugin diff):

```diff
+    [CheckPermission(StandardPermission.Configuration.MANAGE_WIDGETS)]
     public async Task<IActionResult> Configure()
     {
-        if (!await _permissionService.AuthorizeAsync(StandardPermissionProvider.ManageWidgets))
-            return AccessDeniedView();
```

Non-controller checks keep `IPermissionService.AuthorizeAsync(...)` but pass the new string constant. Custom permission providers → `IPermissionConfigManager` (see the plugin-development skill, `references/permissions.md`, for the old→new name table). Store owners must re-assign custom role permissions after upgrading (release notes, issue #7563).

## Admin menu

- **Removed:** `SiteMapNode`, `XmlSiteMap`, `IXmlSiteMap`, `sitemap.config`-based menu.
- `IAdminMenuPlugin` still exists but is `[Obsolete]` and its signature changed to `ManageSiteMapAsync(AdminMenuItem rootNode)`.
- **Use:** `IConsumer<AdminMenuCreatedEvent>` or derive from `BaseAdminMenuCreatedEventConsumer`; `ThirdPartyPluginsMenuItemCreatedEvent` for the "Third party plugins" node.
- `SiteMapNode` properties `ControllerName`/`ActionName`/`RouteValues` → set `AdminMenuItem.Url = eventMessage.GetMenuItemUrl(controller, action)`.

## Other removed / changed APIs

| 4.70 | 4.80 |
|---|---|
| `IAclSupportedModelFactory`, `AclSupportedModelFactory` (Nop.Web.Framework.Factories) | removed |
| `ILocalizedEnum` (Nop.Core) | removed |
| `ILogger.InsertLogAsync(...)` returned `Task<Log>`; `InsertLog` returned `Log` | `Task InsertLogAsync(...)`; `void InsertLog(...)` |
| `IProductService.UpdateHasDiscountsAppliedAsync`, `UpdateHasTierPricesPropertyAsync` | removed (bulk `InsertProductsAsync`/`UpdateProductsAsync` added) |
| `IMessageTokenProvider.AddStoreTokensAsync(tokens, store, emailAccount)` | `+ int languageId` |
| `ICampaignService.SendCampaignAsync(campaign, emailAccount, email)` | `+ int languageId` |
| `IMessageTemplateService.GetAllMessageTemplatesAsync(storeId, keywords, isActive)` | `+ int emailAccountId = 0` (source-compatible) |
| `IAclService` | new `AuthorizeAsync(Customer, IList<int>)` and `AuthorizeAsync(string entityTypeName, int entityId, Customer)` overloads |
| `ITaskScheduler` | new `StartSchedulerAsync()` / `StopSchedulerAsync()` |

Core plugin interfaces (`IWidgetPlugin`, `IPaymentMethod`, `IShippingRateComputationMethod`, `ITaxProvider`, `IDiscountRequirementRule`, `IPlugin`) did **not** change.

## Views (plugins and themes)

- `Views/Product/_ProductReviewHelpfulness.cshtml` moved to `Views/Shared/`.
- New vendor review views (`Catalog/VendorReviews`, `Catalog/_VendorProductReviews`).
- Admin Font Awesome 5.15 → 6.6: check icon class names in plugin admin views.
